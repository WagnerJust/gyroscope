## Next
- [ ] **`install-skill` ignores `$CLAUDE_CONFIG_DIR` — installs to the wrong Claude when two are configured.** `gyroscope install-skill` defaults to `~/.claude/skills` and never consults `CLAUDE_CONFIG_DIR`, so anyone running a second Claude (e.g. `CLAUDE_CONFIG_DIR=$HOME/.claude-personal claude`, the standard work/personal split) silently installs the skill into the *other* agent's config and it never appears in the sessions they meant it for. Confirmed 2026-08-26: a personal-config session could not see the gyroscope skill at all — it had to be read off disk by path. **Fix:** default to `${CLAUDE_CONFIG_DIR:-$HOME/.claude}/skills`; the explicit `[skills-dir]` positional keeps overriding. Cheap, and the failure is silent, which is the argument for doing it. Same defect in `buckle install` (`~/Side/buckle`, no TODO.md yet) and in Scott's `plumbline install-skill --global`, which writes under `$HOME` on the same assumption — worth an upstream issue there rather than a local fix.
- [ ] **The SessionStart hook's payload can outgrow what Claude Code injects — and then almost none of it arrives.** Found 2026-09-21 in carsearchhub. The hook `cat`s `AGENTS.md docs/agents.md TODO.md .local/todo.md .local/local.md gyroscope.json`; there that is ~258 KB (TODO.md ~160 KB, docs/agents.md 87 KB). Claude Code does not inject hook output that large: it saves it to a file and hands the session a **2 KB preview** ("Output too large (285.2KB). Full output saved to … Preview (first 2KB)"), i.e. the top of `AGENTS.md` and nothing else. So gyroscope's premise — the hub, conventions and open work are in context from the first turn — silently fails on a large repo; carsearchhub's own `DONE.md` had noticed the truncation on 2026-09-10 without tracing it here. **Not fixable in the consuming repo:** `gyroscope check` verifies the exact `SessionStartCommand` string, so a local edit reads as drift and `check --fix` / `init --apply` appends the full hook back beside it. **Payloads measured across the gyroscope repos in `~/Side`:** carsearchhub 258 KB, prony 76 KB, notwhoop 26 KB, the other seven 8–15 KB — whether those three or any of the rest are also truncated depends on the harness's threshold, **which is unknown; measure it first** (a throwaway repo whose hook cats files of known sizes, read in a fresh session). **Options:** (a) hub only — inject `AGENTS.md` and let its routes do the rest; simplest, but gives up injecting `TODO.md` for resume, which the state spoke exists for; (b) size-budgeted — inject files in priority order while they fit and emit a one-line pointer for each that doesn't ("TODO.md (161 KB) not injected — read it"), so small repos are unchanged and large ones degrade visibly; the cost is that the hook stops being pure `cat`, a property DONE.md records choosing on purpose. **Either way, `check` should report the payload size and warn past the threshold**, so the failure stops being silent in every repo that uses gyroscope. Leaning (b) plus the warning.
